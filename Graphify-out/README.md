# Graphify-out/

This folder holds the output of the **Graphify** skill — an auto-generated structural graph of the whole codebase (files, dependencies, and how they relate to each other).

- **Don't hand-edit anything in this folder.** It's regenerated, not written.
- Regenerate it after finishing a feature or right before opening a PR (see rule 4 in `AGENT.md`) — not on every small edit.
- If this folder is empty, run Graphify once locally to populate it. The exact invocation depends on how your local Graphify skill/CLI is installed, so it isn't duplicated here — check your own Graphify setup for the command.
